Ask the Sensors

Grounded, explainable activity question answering from wearable signals CS60055 Ubiquitous Computing, IIT Kharagpur — Hackathon Challenge 1

Given a raw accelerometer + gyroscope recording and a natural-language question, the system returns a structured answer about the user's activity and grounds it in the specific stretch of signal that supports it (timestamps, modality, channels, and a signal-based explanation).
